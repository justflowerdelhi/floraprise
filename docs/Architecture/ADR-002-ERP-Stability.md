# ADR-002: ERP remains stable

- Status: Accepted
- Date: 31-Jul-2026
- Decision: ERP remains in stability mode and will not be modified for new mobile-first work unless explicitly approved.

## Reason

ERP is the existing production platform and must remain stable while mobile is being developed independently.

## Consequences

- No ERP route changes for new work.
- No ERP schema changes for new work.
- No ERP authentication changes for new work.
